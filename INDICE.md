# Índice del acervo

Este índice organiza el acervo histórico y documental de Paraíso, Tabasco y Puerto Ceiba. Cada área conserva registros con procedencia y fecha de consulta para facilitar su verificación y recuperación.

| Área | Contenido |
| --- | --- |
| [Historia](historia/README.md) | Procesos, periodos y temas históricos de Paraíso. |
| [Puerto Ceiba](puerto-ceiba/README.md) | Memoria histórica, territorial y comunitaria de Puerto Ceiba. |
| [Cronología](cronologia/README.md) | Acontecimientos ordenados por fecha. |
| [Personajes](personajes/README.md) | Personas y colectivos relevantes. |
| [Documentos históricos](documentos-historicos/README.md) | Documentos históricos y sus fichas descriptivas. |
| [Bibliografía](bibliografia/README.md) | Libros, artículos y otros materiales de consulta. |
| [Fuentes orales](fuentes-orales/README.md) | Testimonios, entrevistas y memorias orales. |
| [Fotografías](fotografias/README.md) | Imágenes y sus metadatos de identificación. |
| [Monografía](monografia/README.md) | Materiales para la monografía histórica y territorial. |
| [Sitio web](sitio-web/README.md) | Contenidos y materiales destinados a su publicación digital. |

## Criterio general de incorporación

- Añadir información verificable y registrar su procedencia.
- Mantener los archivos originales sin alterarlos; describirlos mediante fichas o metadatos cuando sea necesario.
- Evitar crear entradas repetidas: antes de incorporar un registro, revisar el área temática correspondiente.
- Usar nombres de archivo claros, en minúsculas y con guiones, por ejemplo: `1900-inauguracion-del-muelle.md`.
